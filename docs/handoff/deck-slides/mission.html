How the completion mission was organised, and this is the part worth stealing. One orchestrator (kimi-k3) turned the owner’s complaints into a map of who owns what. Seven long-lived specialist agents each owned an exclusive set of files: wildlife (scripts/fp/animals), vehicles, hit impact, collision rigidity, sky-view skyline, sim determinism and the web build with the GMI deploy. Shared files (the feature registry, the signal bus, feature_flags.json, main.gd) go through the orchestrator. The hours shown are active hours per specialist. Around them, 28 short-lived helper sessions: 17 Explorers that only read and map code, and 11 Workers that write. They coordinated with 1,317 messages and 32,555 tool calls across 36 sessions. Wall clock: about 112 hours from the session start on 25 October to the end of the mission on 30 October, 202 hours of agent time, so roughly 1.8 agents were working at any moment.
