Everything GridFall takes from GMI Cloud. Chat models: 14 different models are in the code, one API for all of them; the five mayors each run on their own model, and around them sit the Gazette, the Council Speaker, the Chaos Director, the Grid Operator and the Street Inspector, plus residents with minds of their own. Image model: hy-image-v3.5-preview did two jobs: it drew four concept sheets (environment mood, crisis landmarks, resident avatars, shaders and HUD) that the Blender modelling was built from, and at play time it prints campaign, shop and Gazette posters on the in-game walls. One network door: every call goes through one client with retries, a circuit breaker per role and a replay cache, so with no key or during an outage the game keeps running on recorded answers. AgentBox: the web build is a Docker container on GMI AgentBox, 2 vCPU and 4 GiB, and each player's browser calls GMI with the player's own key, so the server never holds one. On the right, what GMI also offers that GridFall did not use: video and audio models, dedicated endpoints and GPU compute.
