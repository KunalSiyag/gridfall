The wrap-up before the demo; five lessons, each backed by something on the earlier slides. One: spec and gate first. Exclusive file ownership plus a single gate is what let seven agents work in one tree without stepping on each other. Two: documents are memory. The mission’s workspace held 37 markdown documents and 172 screenshots (plans, a web performance budget, measurements), so the plans outlast any single session. Three: budgets are shared and they run out. Usage limits paused the work four times, so commit state early and keep the notes current. Four: review with different eyes; the carjack door clearance and the flag-off claim were both caught by a second agent with a different brief. Five: do not let green lie. Engine ERROR lines now fail the gate, behaviour sits behind flags, and nothing was pushed, pinned or deployed without a person deciding.
