How every change was verified in the hardening phase. The ground rules first: every before-and-after number is compared against a read-only copy of the baseline commit; at most five git worktrees at a time, merged and closed promptly; headless Godot and headless Chrome only; nothing pushed, pinned or deployed without a human decision; and a hand-off note updated at every milestone. Each unit of work then ran through the same four steps as an orchestrated workflow: an implementer; adversarial reviewers, each with a different lens (for example kinematics, integration and determinism, tests and claims); a fixer that must reproduce a finding before fixing it, or reject it with evidence; and a serialized seal step that runs lint, the repo checks and the gate before a single local commit. Numbers for the first six workflows: 153 distinct agents, about 16,600 tool calls and 51 million tokens. Result: 25 commits between 30 October and 2 November, 163 files changed, and 25 new test files.
