The toolbox in one picture, before the detail. Droid is the agent harness; inside it two model families did the work: Claude Opus 5.5 for the first game and the first 46 pull requests, then kimi-k3 for the long completion mission. GMI Cloud is the runtime brain of the game itself (14 chat models for mayors, city agents and residents), drew the concept sheets that the Blender modelling was built from and prints the in-game posters (both with hy-image-v3.5-preview), and hosts the web build on AgentBox. Blender runs headless from Python scripts, so every model can be rebuilt with one command; Godot is the engine and also has an MCP server the agents used to run the game and take screenshots. The people, kits and textures come from open content with licences and provenance on file: Microsoft Rocketbox (MIT), Quaternius animations (CC0), Kenney kits (CC0) and Poly Haven textures (CC0). The music is two ACE-Step 1.5 stems, 96 BPM when the grid is fine and 122 BPM in a crisis, crossfaded by the audio director.
