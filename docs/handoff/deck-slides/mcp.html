MCP is how an agent gets hands. Two MCP servers were configured in Droid: Blender MCP, which lets the agent drive a live Blender, and Godot MCP, which lets it launch the project, evaluate code in the running game and take screenshots. The very first Droid session on 17 October was named “Integrate Blender and Godot MCP” and had three workers on the Blender service models, the model library and realistic assets; that is how the first game got its look. In the completion mission the agents made 205 Godot MCP calls to run the game and look at it. The lesson we wrote into the architecture file (rule D10): assets are rebuilt by headless Blender scripts, because MCP servers are not available inside every agent, and a script can be run again by anyone. Use MCP to explore and to see; use scripts to make the result repeatable. Do not describe a GMI MCP server here: none is configured in Droid, only Blender and Godot. GMI is reached over its API (next to the architecture slides).
