Around them: a Gazette, a Council Speaker, a Chaos Director, a Grid Operator and a Street Inspector, plus residents with minds of their own.

The orbit view and the street now name a mayor the same way: the person first, the model underneath.

Introduce the cast by person first, model second, because that is how the game now shows them everywhere: in the Planner view, on the street, in the log and in the Gazette. The brand names are the models: Argon-4 is google/gemini-4-argon, DeepSeek-V4 is DeepSeek-V4-Flash, Kimi-K3 is moonshotai/kimi-k3, Qwen-3.8 is Qwen3.8-Max, Grok-4.5 is x-ai/grok-4.5. The colour on each card is the colour the game uses for that mayor’s district and card. Around the mayors there are six support agents (Citizen Voices, GridFall Gazette, Council Speaker, Chaos Director, Grid Operator, Street Inspector), and residents are planned in batches of ten over six fast models. Counting every model id in the code gives 14 distinct chat models plus one image model (hy-image-v3.5-preview) that paints the posters on the walls. Side note for the story: until 2 November the orbit view headed each mayor with the model brand while the street used the human name, which made it read like two different cities; commit 83fe2e8 fixed that and a test now guards it. Concept art: generated with an image model during design.
