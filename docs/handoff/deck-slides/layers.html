The one sentence: there is a single simulation, and two views of it. The Planner view and the street are not two cities; they are two renderers of the same CitySim, switched with Tab. The simulation core is about 6,900 lines, seeded and headless: it never touches a scene node, so tests can run it with no display and replay a day exactly. Everything the AI does goes through a single class, GmiClient, which is the only place the game talks to the network. The first-person layer is by far the largest part, 69.5k lines in 186 files, organised as 23 registered feature folders plus the player and the collision world; features talk through a signal bus of 36 signals instead of calling each other. Line counts are at commit 83fe2e8 and were counted per folder with wc -l: sim 6,850; ai 4,721; world 7,628; ui 2,182; ops 2,083; fp 69,486.
