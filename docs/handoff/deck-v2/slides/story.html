The story

How it was built, in order

Dates are 2026. Sources: git history and the Droid session logs; the reasons for the hand-overs are the builder's account.

About 2 minutes. Read it top to bottom like a conversation: amber arrows are requests, cyan dashed arrows are answers. I built GridFall with two coding tools, Factory Droid and Claude Code, and the switches were driven by usage limits. 17 October: I describe the game to Droid, running Claude Opus 5.5. It connects the five mayors to GMI Cloud, asks GMI's image model for concept art, and uses Blender and the Godot engine to build the city and its models. 18 and 19 October: the first-person layer, walking the streets, was built in Claude Code on Opus 5.5 after a Droid usage limit, with many agents working in parallel from written specs. 19 to 25 October: back on Droid with Opus 5.5, delivering the game one feature at a time as 46 reviewed changes. 25 to 30 October, the Droid mission: to get more usage we moved to a Droid Core model, kimi-k3, which goes further on the same allowance. A lead agent split my complaints between seven specialists and ran for five days. 30 October to 2 November: the mission hit its limit too, so Claude Code on Sonnet 5.5 finished the polish and the web build for GMI AgentBox. The point for the audience: everything is written down (specs, notes, tests), so the work could move between tools when a limit hit.
