About 1 minute 30. This is the only architecture slide, so keep it to three boxes. Left, the brains: every decision in the game comes from an AI model on GMI Cloud, the five mayors, five city helpers and the residents. Middle, the city: a normal program that holds the real state of the city. The AI asks for things, the city checks them and says yes or no, which keeps the game fair and stops a model from breaking the rules. Right, the views: the view from above and the street view are two windows onto the same city. Bottom, the safety net: if there is no key, or a model is slow or down, the game replays recorded answers and then falls back to simple rules, so the city never freezes. That is why the demo works even with no internet. If someone asks for more depth, point them to the GitHub project at the end.
