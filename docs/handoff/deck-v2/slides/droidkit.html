Source: Droid session logs, 17 to 30 October 2026. Droid offers more; these are the parts GridFall used.

About 1 minute 30. Four things Droid gave us, in plain words. Models: Droid lets you pick the AI model per session. The first game and the 46 changes after it ran on Claude Opus 5.5 inside Droid. When the Opus allowance ran out we moved the long mission to a Droid Core model, kimi-k3, which goes further on the same allowance, and used Claude Code for the steps either side of it. Missions: a Droid mission is for goals that are too big for one conversation. A lead agent splits the work between specialists. Ours had seven specialists (wildlife, vehicles, hit impact, collisions, skyline, determinism and the web deploy) and ran for five days. Skills: short how-to notes that agents read when they need them. We wrote three: how to add assets, how to add a first-person feature, and how to run the tests. They were used about two hundred times. MCP: a way to plug outside tools into the agent. We connected Blender and the Godot engine, so an agent could build a model or run the game and look at a screenshot. The rule we kept: use MCP to explore, but make the final result repeatable with a script. Droid also offers more than we used here; do not claim anything beyond these four.
