About 45 seconds. The game also runs in a normal browser tab with nothing to install. We exported it from the Godot engine, shrank it (the first load is about 95 megabytes), and put it in a small container on GMI AgentBox. The key idea: the web server never holds a key. Each player pastes their own GMI key into their browser, and their browser talks to GMI directly. With no key the game still runs on recorded answers. Be honest about the picture: it is a screenshot from a software-rendered test browser at the Low quality setting, so it looks flatter than it does on a real graphics card. The new build has not been measured for frame rate in a real browser yet, so do not quote a frame rate.
